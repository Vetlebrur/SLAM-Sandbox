# Visual SLAM sources to explore

A quick list of useful visual SLAM references and implementations:

- ORB-SLAM3: https://github.com/UZ-SLAMLab/ORB_SLAM3
- ORB-SLAM2: https://github.com/raulmur/ORB_SLAM2
- OpenVSLAM: https://github.com/xdspacelab/openvslam
- DSO (Direct Sparse Odometry): https://github.com/JakobEngel/dso
- LSD-SLAM: https://github.com/tum-vision/lsd_slam
- SVO 2.0: https://github.com/uzh-rpg/rpg_svo_pro_open
- VINS-Mono: https://github.com/HKUST-Aerial-Robotics/VINS-Mono
- VINS-Fusion: https://github.com/HKUST-Aerial-Robotics/VINS-Fusion
- Basalt: https://gitlab.com/VladyslavUsenko/basalt
- Kimera: https://github.com/MIT-SPARK/Kimera
- RTAB-Map: https://github.com/introlab/rtabmap
- Open3D SLAM examples: https://github.com/isl-org/Open3D
